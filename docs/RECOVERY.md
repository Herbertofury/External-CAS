# Recovered source lineage

The native implementation builds on the owner's unpublished November 4–5
External CAS work. The original dirty/ignored trees were preserved without
modification in a separate local recovery archive with per-file SHA-256 records.
Private archives, fixtures, catalogs and game/CC assets are not published here.

The isolated research checkout started from TD1 commit
`1ba0986acaebd1d304f4807a58c4f113d2950d2c`. Remote recovery commit
`e0282ea1c43fb3e22b8cc377a27feb4653b8ca79` is a divergent partial recovery,
not a usable release or a simple ancestor of that baseline. Its additional
material-split/dynamic-separates work was preserved independently.

Later local source had real CC rendering, body/skin experiments, pose sequences,
draft and catalog work, much of it ignored by Git. These proven boundaries are
being ported and requalified in Rust. The former browser/Node editor and Rust
browser launcher are reference inputs, not the standalone application runtime.

The owner selected this new public repository with a wiki. CAS-Helper and
Sims4Foundry remain separate projects. Unrelated Apex code/history is excluded.
The active Apex game session, saves, profiles, Mods and source checkout remain
reserved to their owning work. External CAS verification uses read-only installed
resources and disposable project copies; later game tests require an available
disposable session.
