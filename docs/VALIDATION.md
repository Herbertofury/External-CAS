# Native source checkpoint validation

This checkpoint is development source. The complete acceptance checklist remains
open. No installer, full CAS, game synchronization or finished release is claimed.

On Windows with Rust 1.99.0, the exact native-only product tree builds with the
locked dependencies and passes its workspace fixture checks. Installed-source
and original-tool comparisons are explicitly opt-in; they are not counted as
executed merely because a default test command succeeds.

Read-only private checks also exercised this application's own hidden window:

- Five actual installed CC packages: 79 parsed CAS parts, five source-defined
  design groups, five visible thumbnails and real selectable source swatches.
- Nine installed fonts and two actual UI atlases loaded from the selected local
  UI package. Native UI display-list behavior and room parity remain open.
- A selected real garment rendered in the Rust/wgpu viewport, then close/reopen
  restored the same geometry, catalog, thumbnails and exact UI dependency pins.
- Changing only a disposable UI-package copy blocked pinned restoration with an
  explicit source-change error. The original installed package remained unchanged.

Earlier native development checks also restored an actual outfit-slot edit,
verified recovery revision, pose, camera and editor tab. Changed texture sources
blocked restoration. Those checks are documented as development evidence, not
complete imported-Sim appearance or native game acceptance.

Component provenance, real resource counts, independent comparison boundaries
and limitations are documented in each native crate. Sanitized receipts include
asset/CC geometry, LRLE pixels, thumbnail alpha, catalog scope and morphology
comparisons. Private inputs, source package bytes and captures stay excluded.

The Windows workflow checks source builds and generated fixtures on a hosted
runner. It does not have the owner's game, CC or Sims and cannot establish
installed-resource, Tray/game, full appearance, performance or release acceptance.
