# Original static UI host data

The installed source UI expects static tuning as well as Sim data from its host.
Unavailable data can leave the source model's typed-array sentinels intact; an
empty invented response would hide that compatibility failure.

The native static relationship-tuning projection was checked using 15 original
SimData resources. All 239 supported numeric cells matched the independent,
unchanged S4TK reader; 56 unrelated unsupported cells remain opaque with their
original bytes. The native implementation retains provider, ordinal, index and
payload pins and refuses missing or ambiguous references.

The original native marshalling method was separately observed in an isolated
CPU emulator with the exact raw source data and registry layout. It executed
3,881 original instructions and produced the same nested packet as Rust,
including ten family items, four romance items, IDs, localization keys and
relationship maps. Typed UI value operations used hooks modeled from inspected
native helper code. This validates that method/data boundary, not the complete
game or UI VM. No game process was contacted or launched. The original code,
assets, source paths, pins and detailed receipts remain in ignored local storage.

The actual producer returns both family and romance fields to source model
classes that do not declare every field. Their original generic parser reads a
field before catching unsupported writes. That establishes a concrete need for
source-specific missing-public-property read behavior. The private interpreter
experiment preserves ordinary Flash behavior by default, getter exceptions and
sealed writes; it does not strip native packet fields or replace missing user
data. Reentrant source class initialization is a separate explicit compatibility
mode with an own-source regression fixture.

The original UI container advances past those boundaries in isolated testing.
Its remaining menu/copy-filter service inputs and the verified editor snapshot
still need binding. Full UI functionality, all states, native command effects,
font fallback/metrics and visual parity remain acceptance gates.
